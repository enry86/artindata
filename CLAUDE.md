# Dataviz Weekly

Weekly scientific/data visualizations for Instagram and X,
with code published as educational reference.

## Principles
- Aesthetic, almost artistic pieces, but always honest to the data
- Drop default chart chrome; let form carry the data; keep a small key

## Design system
- Palette and background follow the topic (e.g. dark for space,
  earthy on cream for botany), defined as named themes
- Fixed across all posts: typography, layout grid/margins,
  footer with handle + data source, signature mark
- Chosen per post: title alignment, left or centered
  (`Canvas.header(align=...)`), whichever suits the artwork
- Exports: 1080x1350 (Instagram 4:5) and 1600x900 (X 16:9)

## Repo structure
- `dataviz_style/` shared module: fonts, sizes, footer, themes,
  signature mark (`mark.py`)
- `brand/` profile pictures, mark masters and X header, generated by script
  (`python brand/make_brand.py`, `python brand/make_header.py`)
- One folder per post: script, README (source, license,
  what it shows, how it's built), output images
